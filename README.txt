호수벚꽃축제 행사안내·신청 웹페이지 (가상 행사 데모)

실행 방법
1. 압축을 풀고 hosu_blossom_festival 폴더를 엽니다.
2. index.html을 브라우저에서 실행합니다.
3. 사전등록하기 버튼은 register.html로 이동합니다.

파일 구성
- index.html : 행사 메인 페이지
- register.html : 사전등록 페이지 (데모)
- css/style.css : 스타일시트
- js/main.js : 메뉴 및 팝업 기능
- assets/hosu-blossom-poster.png : 제공된 포스터 이미지

참고
- 행사명, 일정, 프로그램, 장소 세부 정보는 디자인 시연을 위한 가상 예시입니다.
- 사전등록 폼은 입력 검증과 완료 화면만 구현되어 있으며 실제 서버 저장/전송은 하지 않습니다.
- Google Fonts 사용 시 인터넷 연결이 필요합니다.
